# File này sẽ được tạo sau khi bạn thiết kế dashboard trên Grafana UI
# và export ra JSON.
#
# Các bước:
# 1. Chạy: docker compose up -d mosquitto influxdb grafana
# 2. Đăng nhập: http://localhost:3000 (admin/admin)
# 3. Tạo Dashboard với 6 panels (xem hướng dẫn README.md)
# 4. Export: Dashboard menu () → Share → Export → Save to file
# 5. Đổi tên file thành smart-building.json và đặt vào thư mục này
